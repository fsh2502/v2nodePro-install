# v2nodePro v0.3.7

Stable release based on Xray Core 26.7.28.

## Changes

- Retains traffic counters until the panel acknowledges each report, avoiding
  traffic loss during temporary API failures.
- Reports online users from active connections more accurately to the panel.
- Fixes first-time installation by copying the packaged sample configuration
  to `/etc/v2node/config.json`.
- Downloads and verifies a package before replacing an installed node. Each
  package now includes the install and management scripts.

## Packages

The release workflow builds packages for 25 Windows, Linux, FreeBSD, macOS and
Android targets. Each ZIP contains the binary, pinned GeoIP and GeoSite data,
sample configuration, scripts, documentation and a package manifest.

Verify downloads with the adjacent `.sha256` file or `SHA256SUMS.txt`.

- Linux x86_64: `v2node-linux-64.zip`
- Linux ARM64: `v2node-linux-arm64-v8a.zip`
- Windows x86_64: `v2node-windows-64.zip`

The standard installer and `v2node update` command find this release through
GitHub's latest-release API.
